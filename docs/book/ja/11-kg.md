# 知識グラフ


実体と、それらのあいだの関係を、チームのドキュメントから抽出する。すべての事実は、それを主張したドキュメントとバージョンまで辿れる。出典なしにグラフへ入るものはなく、その一つの規則から残りが導かれる。

**公開範囲は継承されるもので、割り当てられるものではない。** ある事実がプリンシパルに見えるのは、その言及のうち少なくとも一つが、その人が読めるドキュメントの上にあるときである。言及は行ごとに絞られるので、非公開の覚書の抜粋は、チームが報告書を通してその事実を見られる場合でも非公開のままである。呼び出し元がどの言及も見られない実体は、その人にとって存在しない。そして API はそれを、存在しない ID と区別しない。

**検証が来歴である。** 抽出器はモデルに厳密な形を求め、本文の逐語的な部分文字列ではない抜粋、同じ返答の中に無い実体への関係、名前のない実体を拒否する。ドキュメントの新しいバージョンは、その古い言及に取って代わる。ドキュメントを削除すればその事実は忘れられる。言及が一つも残らなかった実体や関係は刈り取られる。

**意図して狭くしてある。** 重複排除は型と正規化した名前によって行い、型をまたぐ統合はしない。そこは知識グラフが死に行く場所である。グラフの問い合わせ言語はない — 名前の付いた実体から二ホップあれば、人が実際に抱く問いは覆える — 可視化ライブラリもない。タブは出典付きの一覧であり、エージェントの `kg_query` ツールは、そう述べたドキュメントを添えてテキストで答える。
