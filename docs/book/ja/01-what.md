# Telemachus とは何か


## 一段落で言うと

チームが自分たちのドキュメントをアップロードし、それについてモデルと対話し、その上でワークフローを走らせ、結果を見るべき人にだけ共有する — そのすべてを、チームが管理するマシンの上で行う。プラットフォームの実体は、HTTP API、ブラウザコンソール、S3 互換エンドポイント、ワークフローエンジン、スケジューラ、クォータ台帳、プラグイン機構を備えた一つの Racket プログラムである。基盤より上のあらゆる機能 — 翻訳管理、ドキュメントパイプライン、知識グラフ — は、その基盤自身のプリミティブから組み立てられている。それがアーキテクチャそのものであり、同時にアーキテクチャが機能することの証明でもある。

## 原則

これらはスローガンではない。どれも少なくとも一度は設計を変えさせた。

- **クリーンな MIT、純粋なオープンソース。** オープンコアはなく、出し惜しみする上位版もない。以前の Python システムから概念を再利用することはあるが、持ち込まれたのは所有者が書いた Racket と所有者が書いたドキュメントだけである。

- **Racket ファースト。** リファレンス実装は Racket 9.3 CS である。Racket 以外の言語でプラグインを書けることは、明確に要件としていない。データ形式が契約になっている箇所（ワークフロー仕様、ツールスキーマ）があるのは、その形式がそれだけの価値を持つからであって、Racket が障壁だからではない。

- **決定的な依存関係。** ツールチェーンは Nix であり、二つ目は存在しない。Homebrew も conda もなく、デプロイ先のホストに「python のスパイス台所」を作らない。PDF レンダラは依存物であり、グラフ可視化ライブラリも依存物である。どちらも、誰かが本当に必要とするまでは断られてきた。

- **契約が先、バックエンドは差し替え可能。** 永続する製品は SDK の契約、HTTP API、セキュリティモデル、そしてプロトコルである。二つ目の実装が狙うのはそれらであって、Racket のコードではない。生成されるリファレンスが存在するのは、契約をコード自身に書き記させるためである。

- **自前ホスティングとプライバシー優先。** 運用者がモデルの URL を外部に向けない限り、バイト列がインスタンスの外に出ることはない。ブロブストアが組織の名前空間の内側で内容アドレス化されているのは、まさに二つのテナントが互いのファイルについて何かを知ることが決してないようにするためである。

- **印をつけるのではなく拒否する。** 完成したように見える誤った結果は、失敗したステップより悪い。翻訳の下書き生成、フィールド抽出、知識グラフの抽出は、いずれも検証を通らないモデルの応答を拒否する。これはあまりにも頻繁に現れるので、この本の中に独立した節を持っている。

## どこに何があるか

    docs/design/        設計ドキュメントと決定ログ
    docs/reference/     生成物：ツール、ワークフロー、権限、API、プラグイン、SDK
    docs/ops/           運用者向けランブック
    docs/integrators-guide.md  自社製品をこのプラットフォームに載せる
    docs/book/          この本
    refimpl/racketmaximus/
      server/main.rkt   HTTP サーバ：ハンドラ、起動、プラグイン読み込み
      server/routes.rkt 宣言されたルート表
      domain/           モデル：authz, repo, flow, sched, quota, i18n, kg, ...
      pkgs/             db-kit, web-kit, cli-kit, sha2-kit：プラットフォームを知らないライブラリ
      plugins/          同梱プラグイン：doc-indexer, doc-pipeline, knowledge-graph, rs3, ...
      cli/              telemachus-localize, telemachus-docs, telemachus-worker,
                        telemachus-secrets
      static/           コンソール（HTML 一枚）とその英語文字列
      locales/          カタログ：en, ja, nl, es-419
      test/             ユニットスイート、スモークスクリプト、e2e ゲート、モックサーバ
