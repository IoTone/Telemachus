# この本の読み方

Telemachus は、チームの AI ツールとアプリケーションを自分たちのインフラで動かすためのプラットフォームである。この本は、リポジトリをクローンし、変更を加える前にその構造を理解したい開発者のためのものである。短いのは意図的である：`docs/reference/` にある生成されたリファレンスが、すべてのツール、ワークフロー、権限、HTTP ルートを唯一の出典から記録しており、`docs/design/` にある設計ドキュメントが、各サブシステムがなぜその形をしているのかを記録している。この本はその二つをつなぐ組織である — 繰り返し現れる考え方、学ぶのに高くついた決定、そしてコードが意味を持ち始める前に必要となる地図である。
